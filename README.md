# Clippy 📎

A faithful, free recreation of the classic **Microsoft Office Assistant** — the real Clippy, with his authentic sprite, all of his animations, and his classic scripted personality. Pure nostalgia. **No AI, no tracking, no cost.**

> Looking for the AI-powered version with a General Assistant mode? See the separate **Clippy 2.0** project.

## What it does
- 🎭 **The real Clippy** — the genuine Office Assistant sprite, not a redraw.
- 🎬 **All 43 animations** — Greeting, Wave, Print, Save, Thinking, the idle fidgets, and more — listed and clickable in the "Show Everything" window.
- 💬 **Classic scripted personality** — type to Clippy and he replies in character with his famous "It looks like you're writing a letter!" gags.
- 🧑‍🤝‍🧑 **10 assistants** — switch between Clippy, Merlin, Rover, Links, Genius, Bonzi, F1, Genie, Peedy, and Rocky.
- 🪟 **Windows-9x styling** — beveled windows, gradient title bars, draggable panels.

## Run it
Just open **`Clippy.html`** in any modern browser (Chrome, Edge, Firefox). No install, no build step.

> It needs an internet connection **only** to fetch the character sprites from the clippy.js CDN. Nothing else phones home.
